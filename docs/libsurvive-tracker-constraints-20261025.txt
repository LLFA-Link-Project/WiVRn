変更点と限界
新しい静止拘束の段階導入・gyro に応じた緩和は、追跡が落ち着いた汎用 Tracker
に適用される。Index と HMD はこの拘束緩和の対象外。Index の大跳びを解消した
変更ではなく、A の終了ハングの修正でもない。実機での改善はこれから確認する。
Monado の座標変換・履歴・予測計算は変更していない。

上流の minimize-state-space の既定値はまだ 1 なので、Monado は通常起動時も
--kalman-minimize-state-space 0 を明示する。これは全機器に対する状態次元の指定。
それ以外の以下の値は、更新版 libsurvive の既定値と一致する。
比較モードでは全10値を明示し、競合する SURVIVE_* の環境変数を拒否する。

  process-weight-ang-vel = 60
  kalman-minimize-state-space = 0
  process-weight-acc-bias = 1e-8
  process-weight-gyro-bias = 1e-8
  kalman-zvu-stationary-ramp = 0.5
  kalman-zvu-stationary-gyro-scale = 0.02
  kalman-zvu-stationary-velocity-sigma = 0.1
  kalman-zvu-motion-guard-time = 0.5
  kalman-zvu-motion-all-devices = 0
  kalman-align-observation-quaternion = 0

比較モード
記録有効の libsurvive でのみ、WIVRN_SURVIVE_TRACKER_CONSTRAINTS を解釈する。
  new: 上記の10値
  legacy: ramp=0, gyro-scale=0 の2値だけを変更。他の8値は同じ。
角速度雑音は両条件とも60。旧「B=0.6」とは異なる比較で、混在は拒否する。
旧 bias 比較とも併用しない。記録無効の起動では比較用の環境変数は無視する。

選択は survive-settings.json / manifest の tracker_constraints_comparison に残る。
同じファイルの expected_trial_options に全10値を残し、native OPTION の実効値は
native-options.json / manifest の trial_effective_options に保存する。
不一致、設定clamp!=0、記録の破損・終了失敗は complete にしない。
各 Monado 出力の effective_prediction_ns の記録と offline validate も継続する。
通常の起動も native-options.json に実効値を保存する。

起動とマーカー
最初に dashboard/server を終了し、BS を起動する。ダッシュボードの設定は
libsurvive、記録有効、予測clamp 0 ms。以下の補助コマンドもこの設定を確認する。
WiVRn ディレクトリで、新拘束を起動:

  tools/lh-recorder/lh-tracker-test start new

接続して追跡が始まった後、別ターミナルで:

  tools/lh-recorder/lh-tracker-test mark new

案内に沿い、動作の準備ができたら Enter。開始・終了マーカーは自動で残る。
台へ置く、手持ち、回転なしの小さな並進、回転を伴う動き、右Indexの高速回転、
置いた後のIndex復帰、Tracker持ち上げ後の手持ち・小さな動きを別々に記録する。
ジッター・始動遅れ・微動の消失・停止後の滑り・復帰を別々に評価する。
向きを変えた前後で滑りの方向も観察する。

旧拘束の比較は終了後に start legacy / mark legacy を実行する。
次の対は legacy→new と順序を入れ替える。バイナリと他の設定は変えない。
ガイドのマーカーに条件名・開始終了が残り、記録全体の時刻から実行順序を確認できる。

各 start は正常に作れた libsurvive 自身の immutable snapshot を別の書き込み可能な
/tmp/wivrn-survive-constraints-*/config.json へコピーする。live設定は読み直さない。
固定コピー: build-dashboard/diagnostics/handheld-angular-comparison-20261024/baseline.json
SHA-256: c0fd8d7485628f0471b3001e13786cf092bfb06ce66bd384d0740188087dd9da
SteamVR の基地局姿勢は使わない。試行用configは再現用に残す。
起動補助は旧 angular/bias 比較の変数と SURVIVE_INIT_CONFIGFILE を子から外す。
ユーザーの普段の較正・WiVRn設定は変更しない。

固定較正で確認してから、新規較正を別試行で確認する場合:
  tools/lh-recorder/lh-tracker-test start new --fresh
新しい空の試行ディレクトリを作り、configの無い専用パスを渡す。
通常起動へ戻す時は上記の補助を使わず、比較用環境変数を指定せずに起動する。

終了できない場合
SIGKILL 前に全スレッドのバックトレースを採取する:

  sudo gdb -nx -batch -p "$(pgrep -n -x wivrn-server)" \
    -ex 'set debuginfod enabled off' -ex 'set pagination off' \
    -ex 'thread apply all bt 30' -ex detach \
    > ~/WiVRn/wivrn-tracker-constraints-shutdown-bt.txt 2>&1

必要なら採取後に SIGKILL。gzip末尾や最終queue集計の無い記録は complete に
書き換えない。データの読める範囲と終了待ちの原因を分けて調べる。
